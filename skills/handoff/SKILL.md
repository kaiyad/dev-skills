---
name: handoff
description: Compact the current session into a handoff another agent — or you, later — can resume cold. Use when context is full, work spans sessions, or you're asked to hand off, checkpoint, or summarize progress for someone to continue.
---

Write the note that lets a cold reader pick up exactly where this session is, without re-deriving anything. The test is single: could a fresh agent continue from this file alone?

## Steps

1. **Goal and status.** State the objective, then what's **done**, **in progress**, and **not started**. The reader needs the shape of the whole before the details.
2. **Live state.** The branch, the files touched, the current failing test or error message (verbatim), and the single concrete next step. This is what a cold start can't reconstruct — capture it precisely.
3. **Decisions and why.** The choices already made and their reasons, so the next agent doesn't relitigate settled questions or undo deliberate tradeoffs.
4. **Open questions and traps.** What's still unresolved, and the gotchas you hit — the dead ends, the surprising behavior, the thing that looks wrong but isn't.
5. **Write it to a durable file**, not just into chat — a scratch path or a repo doc. A handoff that lives only in a scrolled-past message isn't a handoff.

## Completion

A reader with none of this session's context can resume from the file: goal, status, exact next step, decisions with reasons, and known traps are all present. Nothing load-bearing lives only in your head or the chat history.
